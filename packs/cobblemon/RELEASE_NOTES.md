## Client setup

- Java 21.
- Set the launcher's max memory to **8 GB** on a PC, **6 GB** on a Steam Deck
  (Prism: Settings → Java → Maximum memory allocation; Modrinth App:
  Settings → Java and memory). The `.mrpack` cannot set this for you.
- Shaders are optional: pick one under Video Settings → Shader Packs, K toggles.
